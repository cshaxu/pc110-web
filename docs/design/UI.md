# Web Product Interaction

The first page must make four states clear: no assets loaded, loading, running, and paused/error. While running, Canvas preserves the PC110 640×480 aspect ratio and exposes focus, keyboard capture, and pointer-coordinate transformation as understandable user behavior.

The minimal controls are load BIOS, load font ROM, load disk, start/pause, reset, mute, and import/export session. All imported assets are handled locally. The page explains that users must obtain their own assets and that assets are not uploaded by default.

The existing Easy-Setup, Personaware, and native-script boot paths are experience-regression samples, not application workflows to be reimplemented by the UI.
